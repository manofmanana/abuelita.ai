# 🌹 Abuelita.ai - Bilingual Learning Platform

*Para mi abuelita, Francisca Martínez - Para que nunca más una abuela tenga que esperar a entender el mundo.*

*"So that never again will a grandmother have to wait to understand the world."*

## 🎯 Project Overview

**Abuelita.ai** is a heartfelt bilingual English-Spanish web application that honors the memory of Francisca Martínez by helping Spanish speakers learn English and English speakers learn Spanish through AI-powered translation, tutoring, speech recognition, and cultural learning.

### ✨ Inspiration

This project was born from watching my grandmother navigate a world where language barriers sometimes isolated her from full participation in her community. Every feature in this platform reflects the patience, warmth, and wisdom that she embodied, creating a learning environment that feels like having a loving abuela guide you through language learning.

## 🚀 Features

### 🏠 **Home Page - Smart Translation Hub**
- **File Upload Support**: Translate documents (DOCX, PDF, TXT)
- **AI-Powered Translation**: Uses OpenAI API for contextual, nuanced translations
- **Text-to-Speech**: Hear translations spoken aloud
- **Voice Input**: Speak your text for translation
- **Bilingual Toggle**: Seamless switching between English ↔ Spanish
- **Translation History**: Track your translation sessions

### 🧑‍🏫 **Learn Mode - Interactive Lessons**
- **Adaptive AI Teaching**: Personalized lessons generated by ChatGPT
- **Dual Learning Paths**: 
  - Spanish for English speakers
  - English for Spanish speakers (para hispanohablantes)
- **Progressive Difficulty**: Beginner, Intermediate, Advanced levels
- **Interactive Exercises**: Grammar, vocabulary, and conversation practice
- **Progress Tracking**: Monitor your learning journey
- **Cultural Context**: Every lesson includes cultural insights

### 🎨 **Culture Mode - Idioms & Wisdom**
- **Cultural Expression Database**: Idioms, slang, sayings, and jokes
- **AI Cultural Explanations**: Deep context and usage examples
- **Abuelita Mode**: Warm, grandmother-style explanations with personal touches
- **Searchable Content**: Find specific phrases or browse by category
- **Bilingual Examples**: See expressions used in both languages

### 💖 **About Page - Tribute to Francisca**
- **Heartfelt Biography**: The story behind Abuelita.ai
- **Photo Gallery**: Memories and moments (placeholder for personal photos)
- **Interactive Elements**: Optional mariachi background music
- **Mission Statement**: Bilingual dedication to bridging communities

## One-line pitch

Abuelita.ai is a full-stack bilingual (English ⇄ Spanish) web application that combines AI-powered translation, bilingual micro-lesson generation, and practical document translation to help families and learners bridge language gaps with warmth and cultural context.


## Current status (short)

- Web app implemented in Django with a responsive Bootstrap frontend.
- Translation Hub supports text input and file uploads (TXT / DOCX / PDF), returns a translation result and a downloadable translated file.
- Bilingual lesson generator (EN/ES) produces phrase lists, examples, phonetic hints, and a mini-quiz; generator no longer returns per-item "exercise" objects and cloze hints have been removed.
- Deterministic DOM IDs and stable response prefixes added for reliable automated tests.
- Translator UI has robust AJAX behavior, copy/listen/download controls, and a language-pairing rule enforced in the client (auto-switch to Spanish when source is English and vice versa).
- Extensive automated tests: current suite passing locally (47 tests + warnings).


## Why I built this — a personal note

Spanish was my first language. My grandmother, Francisca Martínez, never learned English. When I was a child and later as an adult I would help her with daily tasks that required reading English — from doctor notes to legal forms — and I remember the small dignity both of us felt when she could finally understand something on her own.

She would often ask me to read contracts and letters out loud, to explain what certain words meant, or to teach her how to say a phrase so she could feel confident in a new situation. Those moments—gentle, intimate, practical—are the heart of Abuelita.ai. This project is both a technical exercise and a tribute: building tools that bring language, context, and a little human warmth back to people who need it most.


## Highlights

- Full-stack scope: Django backend, Bootstrap frontend, vanilla JS for AJAX interactions.
- Bilingual focus (en/es) with i18n parity and tests to ensure both languages are supported.
- Document translation flow: upload → translate → download (preserves text formatting where possible).
- Lesson generator with phonetic hints (parallelized for performance) and deterministic outputs for reproducible tests.
- Strong test coverage for templates, views, and generator contracts.


## Quick start (local development)

Prereqs: Python 3.11+, git

1. Clone and enter the repo

```bash
git clone <repo-url>
cd abuelita-ai-project
```

2. Create and activate a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Apply migrations

```bash
python manage.py migrate
```

5. Run tests

```bash
python -m pytest -q
```

6. Run the dev server

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000


## Running the translation hub (notes)

- The home/index page contains the Translation Hub. You can type text or upload a supported document. The server returns a translation and (for uploads) a downloadable translated file.
- AJAX clients receive JSON with keys `translation_result` and optionally `download_url` for the translated artifact.


## Developer notes & decisions

- The generator no longer includes per-item `exercise_en`/`exercise_es` objects and cloze hints were removed from both backend and UI.
- Phoneticization and paraphrase tasks were parallelized using a shared ThreadPoolExecutor to improve throughput.
- Avoid import-time side-effects that trigger Django errors during test collection (lazy imports in views where necessary).
- The test suite enforces single-line `{% trans %}` tags across templates; templates were audited to satisfy this requirement.


## Tests & verification

- The project uses pytest along with Django's test utilities. The focused translator tests are under `translator/tests/`.
- A small script (`scripts/check_trans_tags.py`) verifies single-line `{% trans %}` usage.
- Run all tests with:

```bash
python -m pytest -q
```
